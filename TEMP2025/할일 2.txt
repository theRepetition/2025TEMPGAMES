인벤토리 만들기


구조 -> 기존 시스템에서 변경 단, 장착중인 아이템은 분리해서 위에 리스트 따로 나와야 함

플레이어 기준 작동 방식
-> 필드의 아이템 f 키 눌러 상호작용 -> (인벤토리에 추가)
->인벤토리 창을 열어 목록에 수록된 아이템 확인 가능
-> 클릭 -> (현재 선택중인 아이템으로 표시) -> 더블클릭 -> 장착됨



게임 로직
-> 필드의 아이템 f 키 눌러 상호작용 -> (인벤토리에 추가) //이미 구현완료된 부분

->인벤토리 창을 열어 목록에 수록된 아이템 확인 가능 // 리스트에 외부 위젯을 기반으로  아이템 생성
-> 클릭 -> (현재 선택중인 아이템으로 표시) // 해당 리스트 위젯을 변수에 저장해 이후 사용하게끔
-> 더블클릭// 더블 클릭시 현재 장착된 아이템 기준으로 로직 처리
// 현재 장착 부위 상태
1.장착중이지 않음
1-1 아이템 갯수 1개 -> 인벤토리에서 제거하고 프로필로 옮기기, 선택중인 아이템 비우기
1-2 아이템 갯수 여러개 -> 인벤토리에서 1개 줄이고 프로필로 옮기기, 선택중인 아이템 비우기 -> 그런데 둘다 인벤토리 컴포넌트의 removeitem으로 처리 가능

2.장착중인 아이템 있음
2-1. 장착중인 아이템과 장착하려는 아이템이 같음 -> 해당 아이템(선택중인 아이템)을 프로필 구조체에서 제거하고 인벤토리에 갯수+1(인벤토리 로직 add사용) 선택중인 아이템 유지
2-2. 다른 경우 -> 기존의 아이템을 프로필에서 제거후 인벤토리에 추가하고 선택중인 아이템을 해당 아이템으로 바꾸기, 기존의 선택중인 아이템은 프로필에 넣고 인벤토리에서 제거

무기나 장신구 같이 2개씩 장착하는 경우
1. 오른손 빔 -> 그냥 오른손에 추가
2. 오른손 비지 않음
2-1 왼손 빔 -> 그냥 왼손에 추가
3. 양손 비지 않음
3-1 같은 아이템 장착중일때 -> 어느손이건 해당 아이템 프로필에서 제거후 인벤토리에 추가 
3-2 다른 아이템 장착중일때 -> 해당 아이템 프로필에서 제거후 인벤토리에 추가후 선택한 아이템 장착 (오른손 만 변경)
왼손은 우클릭 더블클릭해서 장착하는 식으로



 -> 장착됨
