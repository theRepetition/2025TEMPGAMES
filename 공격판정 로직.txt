



막기/회피/완벽한막기/처내기/반격 준비
지금은 임시로 막기가 피격 판정과 동일시 되지만 이후에 공격자가 공격시에 먼저 공격 애니메이션 시작시(플레이어로 치면 마우스 버튼을 누른 순간) 피격자에게 이벤트 시작을 알리고 피격자가 어떤 행동을 하는지에 따라 향후 결과 처리

막기 -> 피해 입었을때 막기 상태 확인-> 방향 체크 -> true면 막기로 상대 지구력 감소, 받는 피해 0

회피 -> 단순하게 회피버튼 눌렀을때 근접 공격 판정에서 벗어나게 -> 공격시 회피 상태인 경우 반격으로 연결 가능(n초동안)

완벽한 막기 -> 피해 입었을때 막기 상태 확인 -> 방향체크-> 시간 체크-> 
막기 시작한지 얼마 안되었거나 피해 입자마자 막기 버튼 누른 경우(조정된 난이도와 향상된 UX를 위해) ->
true면 상대 지구력 소모, 받는 피해 0 -> 반격으로 연결 가능(n초 동안)

처내기 -> 공격자의 공격 모션 시작을 피격자에게 전달-> 방향 체크-> 공격 버튼을 눌렀는지 체크 -> 
방향이 일치하고 공격 버튼을 피해 입기전에 누른 경우 -> 처내기 판정 -> 받는 피해 0 상대 비틀거림 -> 반격으로 연결가능
